## Files
- index.html
- style.css
- script.js
- assets/profile.jpg

## Publish
Upload these files to the root of `jaspreet5284.github.io` and keep `assets/profile.jpg` inside the `assets` folder.

The site uses Google Fonts from the web and otherwise has no framework/build step.
